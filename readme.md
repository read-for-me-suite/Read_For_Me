Nouvelle architecture modulaire avec une séparation nette entre le cœur applicatif (core/), les modes fonctionnels (modes/) et la couche matérielle (hardware/). 

Elle inclut le mode Date & Heure opérationnel, un système de gestion des modes propre et extensible.

Refonte complète du sélecteur rotatif : détection stabilisée, gestion par pas plus fiable, traitement robuste des appuis courts et longs.
